# Auto Handel Assistent 3.1

Complete gesynchroniseerde release voor GitHub Pages / Android PWA.

## Wat deze versie doet
- Marktplaats-link delen naar Auto Handel via Android share target.
- Probeert automatisch vraagprijs, kilometerstand en kenteken uit gedeelde tekst of advertentielink te halen.
- Haalt automatisch RDW-voertuiggegevens op zodra een kenteken bekend is.
- Toont APK-restduur.
- Analyseert advertentietekst op pluspunten, minpunten en ontbrekende informatie.
- Toont bevestigde minpunten, meegenomen onzekerheden, totale mincorrecties en netto advertentiecorrectie.
- Ondersteunt drie of meer handmatig te controleren benchmarks.
- Berekent marktwaarde, snelle verkoopwaarde, openingsbod, maximaal bod en handelskans.
- Genereert een onderbouwd bodbericht.

## Belangrijk
Automatisch uitlezen van externe advertenties kan door de website worden geblokkeerd. De app valt dan terug op gedeelde titel/tekst en handmatige correctie.

Upload alle bestanden uit deze release rechtstreeks naar de hoofdmap van de GitHub-repository.
